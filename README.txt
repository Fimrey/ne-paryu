НЕ ПАРЮ — версия для установки на главный экран

Почему нужен хостинг: Chrome предлагает «Добавить на главный экран» только для
страниц по https. Файл, открытый из проводника (адрес начинается с content:// или
file://), такой пункт не получает — и, что важнее, Chrome запрещает таким страницам
localStorage, поэтому прогресс не сохраняется между запусками.

КАК ПОСТАВИТЬ (2 минуты, без регистрации и без Android Studio):

1. Откройте app.netlify.com/drop в браузере (можно прямо с телефона).
2. Перетащите туда ВСЮ эту папку целиком — не отдельные файлы.
3. Netlify выдаст адрес вида https://random-name-123.netlify.app
4. Откройте этот адрес в Chrome на телефоне.
5. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

Появится обычная иконка. Приложение запустится без адресной строки, будет работать
полностью офлайн и сохранять данные. Интернет нужен ровно один раз — при установке.

Чтобы адрес не пропал через сутки, в Netlify можно бесплатно зарегистрироваться и
закрепить сайт за собой. GitHub Pages подойдёт так же.

ФАЙЛЫ
  index.html            — приложение
  manifest.webmanifest  — имя, иконка, цвета
  sw.js                 — кэш для офлайн-работы
  icon-192.png / icon-512.png — иконки
