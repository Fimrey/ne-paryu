# Синхронизация и уведомления — настройка

## 1. Уведомления

Ничего настраивать не нужно: откройте приложение → **Ещё → Уведомления → Включить**
и разрешите запрос. Придёт пробное уведомление — значит работает.

Если приложение стоит как APK из PWABuilder, пересоберите пакет с включённой
опцией **Notifications** (в настройках Android-пакета на pwabuilder.com). Без неё
Android не даст приложению показывать уведомления. На Android 13 и новее система
дополнительно спросит разрешение при первом запуске.

**Что гарантировано:** рубеж, пройденный за время вашего отсутствия, прилетит
уведомлением при следующем открытии приложения.
**Что не гарантировано:** уведомление ровно в момент рубежа, когда приложение закрыто.
Браузер даёт фоновую проверку не чаще раза в 6 часов и только тем приложениям,
которыми регулярно пользуются. Точность «секунда в секунду» умеет лишь нативная сборка.

## 2. Синхронизация через Google

Данные лежат в скрытой папке приложения на вашем Google Диске: ни в интерфейсе Диска,
ни другим приложениям этот файл не виден, у меня и ни у кого другого доступа к нему нет.
Сервера посередине тоже нет — телефон общается с Диском напрямую.

Один раз нужно завести собственный ключ доступа. Пятнадцать минут, бесплатно.

### Шаги

1. Откройте **console.cloud.google.com**, войдите своим аккаунтом.
2. Вверху создайте проект — название любое, например `Ne Paryu`.
3. **APIs & Services → Library**, найдите **Google Drive API** → **Enable**.
4. **APIs & Services → OAuth consent screen**:
   - User type: **External** → Create
   - App name: `Не парю`, почта поддержки и почта разработчика — ваша
   - Scopes можно пропустить
   - **Test users** → добавьте свой gmail. Это важно: без этого вход не пройдёт.
5. **APIs & Services → Credentials → Create credentials → OAuth client ID**:
   - Application type: **Web application**
   - **Authorized JavaScript origins** → Add URI → `https://fimrey.github.io`
     (именно домен, без пути и без слеша на конце)
   - Create → скопируйте **Client ID** (длинная строка, оканчивается на
     `.apps.googleusercontent.com`)
6. В приложении: **Ещё → Синхронизация → Указать Client ID** → вставьте → Сохранить.
7. **Войти через Google**. Появится экран «Google не проверил это приложение» —
   это нормально для личного проекта: **Дополнительные настройки → Перейти
   (небезопасно)**. Проверка нужна только тем, кто раздаёт приложение чужим людям.

### Как это работает дальше

- При каждом изменении данные уходят в облако через несколько секунд.
- При запуске приложение забирает облачную копию и сливает с местной.
- Если версии разошлись, побеждает более свежая; побеждённые тягой и рекорд
  берутся максимальные, так что достижения не теряются.
- Без сети приложение работает как обычно, выгрузка произойдёт при следующем запуске.

### На втором телефоне

Поставьте приложение, вбейте тот же Client ID, войдите тем же аккаунтом —
данные подтянутся сами.

## 3. Если возиться с Google не хочется

**Ещё → Резервная копия → Скопировать код**. Получите строку, перешлите её себе
любым мессенджером, на другом телефоне — **Вставить код**. Работает всегда,
без интернета и настроек, но переносить нужно вручную.
